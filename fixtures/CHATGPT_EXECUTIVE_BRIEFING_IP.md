# 3. THE FIVE COMMERCIAL GATES

Every project must pass at least four of five gates.

### GATE 1 — MONEY
Does the system clearly make, recover, protect, or save money?
Identify: money at risk, money recovered, cost avoided, time saved, conversion improvement, retention impact, economic assumptions.
Never invent customer financial results. Use simulation when real customer data does not exist.

### GATE 2 — PAIN
Is the problem sufficiently painful that someone would actually pay to eliminate it?
Define: who experiences the pain, how frequently it occurs, current workaround, cost of the workaround, consequences of doing nothing.

### GATE 3 — DEMO
Can the value be understood in approximately 30–60 seconds?
Every project must have an interactive demonstration showing:
BEFORE → DETECTION → DECISION → AUTOMATION → AFTER.
Avoid demos that merely show a dashboard. The viewer must understand what the system DOES.

### GATE 4 — BUYER
Identify the actual economic buyer (Founder, CEO, COO, Practice Owner, Operations Manager, Agency Owner, eCommerce Director). Never say simply "Businesses."

### GATE 5 — ENGINEERING
Every system must demonstrate professional engineering: clean architecture, typed interfaces, validation, error handling, deterministic business rules, tests, edge cases, security, auditability, observability, idempotency, and clear deployment instructions.
